# arytmi-app

Det, der ligger på **app.arytmi.com**: Arytmi som app på hjemmeskærmen (PWA).

**Ret intet her.** Alt i repoet er et resultat. Kilden er det private
`Arytmi`-repo, og indholdet skubbes hertil med `npm run udgiv-app` derfra:
`lav-www.js` samler appens filer i `www/`, og de lægges her uændret.
Hver commit siger, hvilken commit i `Arytmi` den er udgivet fra.

`CNAME`, `.nojekyll` og denne fil er de eneste, der bor her fast.
